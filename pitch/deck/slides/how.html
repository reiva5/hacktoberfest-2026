If asked how it works: a crawler fetches public program pages, we strip them to text, Gemma fills a fixed schema including eligibility, validation rules flag bad output, and duplicates collapse to the organiser’s own page. Because there are no CSS selectors, a redesign doesn’t break us: we showed a restyled page in the demo.
