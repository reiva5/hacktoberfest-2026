# Pitch deck

Owner: @adhibskr. A snapshot of the [pitch deck](https://claude.ai/artifact/5R7KsFVBwNFipqC7NsrDCf), kept here so the team can review changes in a PR.

**The live deck is the source of truth.** Edit it there, then copy the files back here. These files are not built or served from the repo.

| File | What it is |
|---|---|
| `deck.json` | Title, slide order, sections and the font (Manrope) |
| `slides/<id>.html` | One slide each, on a 1920×1080 canvas. Speaker notes are in the `<aside>` at the end |

Slide order: cover, problem, scope, why, gemma, numbers, demo, gapmap, next, close. `how` and `trust` are backup slides for questions.

The timed script that goes with these slides is in [docs/DEMO.md](../../docs/DEMO.md).
