Where Gemma 4 works

Gemma 4 does the reading

Three jobs, one open model. Every call returns JSON checked against a fixed schema, so we never parse free text.

Gemma 4 31B through the Gemini API. The same code runs Gemma 4 on your own servers.

Gemma 4 does all the reading in this product, in three jobs. One: it reads a founder’s pitch deck, with the slides sent as images, and returns a profile that cites the slide each field came from. Two: it reads program pages in any ASEAN language and returns a structured English record, eligibility rules included. Three: it decides whether a newly found link is a program page, which is how the source list grows. We run Gemma 4 31B through the Gemini API; because it’s an open model, the same code can run it on Startup ASEAN’s own servers. Every call returns JSON validated against a fixed schema. You’ll see the first two live in a moment.
